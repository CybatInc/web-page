Cloudflare Integration Guide_

The Cybat Cloudflare Integration combines out-of-band edge behavioral telemetry with automated Cloudflare WAF IP access rule enforcement. By deploying the lightweight Cybat Edge Collector as a Cloudflare Worker, your APIs gain deep zero-day logic inspection and JA4 client fingerprinting with 0 ms added latency to origin responses.

⚡ 0 ms Added Latency

Origin requests are forwarded immediately; telemetry is dispatched asynchronously out-of-band using ctx.waitUntil().

🔒 In-Memory Redaction

Authorization headers, Bearer tokens, cookies, and sensitive credential fields are stripped inside the edge isolate before transit.

🛡️ Bidirectional WAF Sync

Cybat's autonomous SOC AI agent creates edge IP blocks in Cloudflare WAF, and automatically clears rules on resolution or thumbs-down feedback.

🏛️ How the Edge Collector Works

Traditional inline proxies introduce latency-inducing network round-trips. Cybat decouples origin response delivery from security telemetry:

Connect Cloudflare During Workspace Registration

When activating your subscription via the Register with Cybat link (from Google Cloud Marketplace or your organization's onboarding invite), configure Cloudflare as your automated edge defense provider:

  1. Select Autonomous Defense Provider: On the Cybat registration screen, choose Cloudflare (WAF).
  2. Organization Profile: Enter your Company Name (e.g. LatAm - Fintech 21-500 - GCP & Cloudflare — jump to Step 2 ↓), unique Organization / Workspace ID, and your Admin Email (used for Google SSO sign-in).
  3. Cloudflare WAF Autonomous Blocking Credentials:
    • Cloudflare API Token: A scoped bearer token created in your Cloudflare dashboard with Firewall Access Rules: Edit permission (jump to Step 2: Create Scoped Cloudflare API Token below ↓).
    • Cloudflare Account ID: Your 32-character hexadecimal account identifier found in the Cloudflare dashboard.

      Where to find it: In Cloudflare Dashboard, select any domain/zone → on the Overview page, scroll down the right-hand sidebar to the API section to copy Account ID (or copy directly from your browser URL: dash.cloudflare.com/<ACCOUNT_ID>/...). Jump to Step 2.E: Retrieve Account ID ↓ for details.

    • Cloudflare Zone ID (Optional): Specific 32-character zone identifier if you prefer restricting automated IP blocks to a specific domain zone rather than account-wide.

      Where to find it: In Cloudflare Dashboard, select your target domain (e.g. yourdomain.com) → on the Overview page, scroll down the right-hand sidebar to the API section. Zone ID is displayed directly above Account ID with a 1-click copy button. Jump to Step 2.F: Retrieve Zone ID ↓ for details.

  4. Confirm & Register: Check the confirmation box verifying that the API token has Firewall Access Rules permissions, then click Activate Account. Credentials are encrypted at rest using Google Cloud KMS and utilized by Cybat's autonomous SOC AI agent to block malicious IPs.

💡 Already have an active Cybat account?

If your workspace is already active, sign in directly at intelligence.cybat.co and proceed directly to Step 3: Deploy the Edge Collector.

Create the Scoped Cloudflare API Token

Cybat uses standard least-privilege Cloudflare API Tokens (never use Global API Keys). Follow these steps in the Cloudflare Dashboard:

A. Navigate to API Tokens

Sign in to dash.cloudflare.com. In the top-right corner, click your user icon → My Profile → select API Tokens in the left sidebar.

B. Create a Custom Token

Click Create Token, scroll to the bottom under Custom Token, and click Get started.

C. Set Required Permissions

Name your token (e.g. Cybat SOC AI WAF Integration) and configure the following permissions:

Scope Permission Category Access Level Purpose
Account Firewall Access Rules Edit Allows Cybat SOC AI to create & delete IP blocks across your account.
Account Account Settings Read Allows Cybat to verify account credentials & validate account ID.
Zone (Optional) Firewall Services Edit Enables zone-level rule targeting if you restrict blocks to specific zones.

D. Set Resources & Create

  • Account Resources: Select Include → All Accounts (or your specific production account).
  • Zone Resources (Optional): Select Include → All Zones.
  • Click Continue to summary, review settings, then click Create Token.
  • Important: Copy the generated API Token immediately. Cloudflare does not store plain-text tokens and will never display it again.

E. Retrieve Your Cloudflare Account ID

The Account ID is a unique 32-character hexadecimal identifier required to register your Cloudflare organization in Cybat. You can find it using any of these methods:

  • From Any Domain Overview: In the Cloudflare Dashboard, click on any domain/zone in your account. On the Overview page, scroll down the right-hand sidebar to the API section and click Click to copy under Account ID.
  • From Browser URL: When viewing any account page or domain in Cloudflare, your 32-character Account ID appears directly in the URL: dash.cloudflare.com/<32_CHARACTER_ACCOUNT_ID>/...
  • From Workers & Pages: In the left navigation bar, navigate to Workers & Pages (or Compute) → your Account ID is displayed in the right sidebar.

F. Retrieve Your Cloudflare Zone ID (Optional)

The Zone ID represents a specific domain in your Cloudflare account (e.g., api.yourcompany.com). It is optional: if left blank, Cybat applies autonomous remediation rules across all zones in the account.

  • Where to find it: In Cloudflare Dashboard, click on the specific domain/website you wish to isolate.
  • On the domain's Overview tab, scroll down the right-hand sidebar to the API section.
  • Zone ID is listed directly above Account ID. Click Click to copy to grab the 32-character string.
Test Your Cloudflare API Token: 
curl -s -X GET "https://api.cloudflare.com/client/v4/user/tokens/verify" \
  -H "Authorization: Bearer YOUR_CLOUDFLARE_API_TOKEN" | jq .

Expected response: {"result": {"status": "active"}, "success": true}.

Deploy the Edge Collector via Cybat Dashboard

You do not need to install local CLI tools or manage code. The Cybat Edge Collector deploys directly into your Cloudflare account in one click through the Cybat Intelligence Dashboard:

1-Click Deployment via the API Keys Section

ZERO CODE
  1. Open the API Keys Section: Log in to the Cybat Intelligence Portal and navigate to API Keys from the sidebar (or visit https://intelligence.cybat.co/#/api-keys).
  2. Copy Your Cybat API Key: Copy your active Cybat API Key (or generate a dedicated key for edge telemetry). You will need this key during the Cloudflare deployment prompt.
  3. Click "Deploy to Cloudflare": In the prominent Cloudflare Worker Edge Collector banner at the top of the API Keys page, click the orange Deploy to Cloudflare button.
  4. Authorize & Provide API Key: Cloudflare will open in a new tab. Select your target Cloudflare account, review the worker deployment, and paste your Cybat API Key when prompted for the CYBAT_API_KEY secret.
  5. Finish Deployment: Click Deploy. Cloudflare will automatically build and provision the edge collector worker into your global edge network.

Attach Worker Route to Your Domain / API Zone

Once deployed, tell Cloudflare which incoming traffic to route through your edge collector:

  1. In your Cloudflare Dashboard, navigate to Compute (Workers) → Workers & Pages.
  2. Click on the newly deployed worker (cybat-edge-collector).
  3. Go to Settings → Triggers → Routes and click Add route.
  4. Set your target route pattern (e.g. api.yourdomain.com/* or yourdomain.com/api/*).
  5. Select your active Cloudflare Zone from the dropdown and click Save.

Verification & Operational Lifecycle

Once traffic hits your routed domain, the collector automatically begins streaming out-of-band behavioral signals:

  • 3D Threat Globe: Inbound requests appear in real time on the Cybat dashboard with Cloudflare edge ray IDs and JA4 client fingerprint attributes.
  • Automated Exploit Blocking: When a request matches zero-day exploit logic (such as BOLA, IDOR, or SQL injection), Cybat's autonomous SOC AI agent instantly creates an active rule in Cloudflare WAF: 
    curl -s -X GET "https://api.cloudflare.com/client/v4/accounts/{account_id}/firewall/access_rules/rules" \
  -H "Authorization: Bearer YOUR_TOKEN" | jq '.result[] | {id, ip: .configuration.value, mode, notes}'
  • 1-Click Unblock & False Positive Handling: Clicking Thumbs Down on an incident in the Cybat dashboard automatically purges the rule across Cloudflare WAF (user, zone, and account scopes). Clicking Thumbs Up re-evaluates and re-blocks active threats automatically.
