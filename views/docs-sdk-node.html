Node.js SDK Reference_

Express middleware, Fastify plugin, and NestJS adapter that reports HTTP traffic directly to the Cybat Intelligence Engine.

● AVAILABLE NOW @cybat/sdk-node on npm Node.js 22+ Zero runtime dependencies

Quick Start_

Four steps from an empty terminal to live detection.

1.

Install the package

npm install @cybat/sdk-node
2.

Create an API key

From the Intelligence Portal → API Keys. Store it as CYBAT_API_KEY.

3.

Add the middleware

One import, one middleware call — see Framework Code Samples below.

4.

Generate traffic, watch the dashboard

Requests appear in the Intelligence Portal within seconds — app listed as Connected, Threat Globe populating, incidents in the feed.

Express Integration

Mount cybatExpress early in your middleware pipeline so it wraps all incoming routes:

import express from 'express';
import { cybatExpress } from '@cybat/sdk-node';

const app = express();

// Mount early before route handlers
app.use(cybatExpress({
  apiKey: process.env.CYBAT_API_KEY!,
  gcpProjectId: process.env.GCP_PROJECT_ID!,
  serviceName: 'user-api',
  captureBody: true,
  extraSensitiveKeys: ['account_number', 'ssn_last_4']
}));

app.get('/api/users', (req, res) => {
  res.json({ status: 'ok' });
});

app.listen(3000);

Fastify Integration

Register cybatFastify with your Fastify instance:

import Fastify from 'fastify';
import { cybatFastify } from '@cybat/sdk-node';

const fastify = Fastify({ logger: true });

cybatFastify(fastify, {
  apiKey: process.env.CYBAT_API_KEY!,
  gcpProjectId: process.env.GCP_PROJECT_ID!,
  serviceName: 'payment-service',
});

fastify.get('/health', async () => ({ status: 'ok' }));

fastify.listen({ port: 3000 });

NestJS Integration

Mount in your main.ts bootstrap function:

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { cybatExpress } from '@cybat/sdk-node';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.use(cybatExpress({
    apiKey: process.env.CYBAT_API_KEY!,
    gcpProjectId: process.env.GCP_PROJECT_ID!,
  }));
  await app.listen(3000);
}
bootstrap();

Configuration Reference_

Option Type Default Description
apiKey string Required Raw API key generated from Intelligence Portal → API Keys.
gcpProjectId string undefined Your GCP Project ID for cloud routing and automated VPC Firewall / Cloud Armor blocking.
awsProjectId string undefined AWS Project ID for AWS cloud routing.
serviceName string undefined Label identifying which service generated the telemetry (shown on incidents).
captureBody boolean false Captures request body excerpts. Redacted in-process before leaving server.
extraSensitiveKeys Iterable<string> undefined Extra field names to treat as secrets for masking (e.g. ['account_number']).
statusFilter 'all' | 'errors' | fn 'all' Controls which captured response status codes are reported.
flushIntervalMs number 2000 How often to flush buffered telemetry events in milliseconds.
maxRetries number 2 Max exponential backoff retries on transient network failures.
