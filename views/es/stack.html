Vertex AI y Gemini

Empleamos Gemini 3.1 Flash para inferencia de solicitudes a alta velocidad. Aprovechando su amplia ventana de contexto, Cybat AI analiza patrones de tráfico para detectar ataques DDoS sigilosos e intentos de inyección.

Capa de Ejecución

Cloud Run Sin Servidor

Nuestro motor de procesamiento se ejecuta en funciones sin servidor sobre Cloud Run que escalan a cero entre ataques y responden al instante bajo carga: sin clústeres que aprovisionar ni cómputo inactivo que pagar.

Capa de Pipeline

SDK y API Gateway

El SDK de Cybat transmite telemetría de solicitudes directamente desde su aplicación hacia API Gateway, que valida cada petición en el borde antes de que alcance nuestro cómputo; luego Pub/Sub amortigua la carga evitando la pérdida de señales durante un pico.

Plano de Control

Marketplace y API

La integración es 100% automatizada. Active al instante directamente desde Google Cloud Marketplace sin tener que implementar canalizaciones de infraestructura. Administre políticas de seguridad, incidentes activos y mitigación automatizada a través de nuestro portal y APIs.
