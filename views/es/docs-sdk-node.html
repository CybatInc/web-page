Referencia SDK Node.js_

Middleware para Express, plugin para Fastify y adaptador para NestJS que reporta el tráfico HTTP directamente a Cybat Intelligence Engine.

● DISPONIBLE AHORA @cybat/sdk-node en npm Node.js 22+ Cero dependencias de ejecución

Inicio Rápido_

Cuatro pasos desde una terminal vacía hasta la detección en vivo.

1.

Instalar el paquete

npm install @cybat/sdk-node
2.

Crear una clave API

Desde el Portal de Inteligencia → API Keys. Guárdela como CYBAT_API_KEY.

3.

Agregar el middleware

Una importación y una llamada de middleware; consulte los Ejemplos de Frameworks a continuación.

4.

Generar tráfico y monitorear el panel

Las peticiones aparecen en el Portal de Inteligencia en segundos: la app listada como Conectada, el Globo de Amenazas poblándose e incidentes en el feed.

Ejemplos de Frameworks_

Seleccione su framework para ver fragmentos de integración listos para copiar y pegar.

Integración con Express

Monte cybatExpress al inicio de su canal de middleware para abarcar todas las rutas entrantes:

import express from 'express';
import { cybatExpress } from '@cybat/sdk-node';

const app = express();

// Montar al inicio antes de los controladores de rutas
app.use(cybatExpress({
  apiKey: process.env.CYBAT_API_KEY!,
  gcpProjectId: process.env.GCP_PROJECT_ID!,
  serviceName: 'user-api',
  captureBody: true,
  extraSensitiveKeys: ['account_number', 'ssn_last_4']
}));

app.get('/api/users', (req, res) => {
  res.json({ status: 'ok' });
});

app.listen(3000);

Integración con Fastify

Registre cybatFastify en su instancia de Fastify:

import Fastify from 'fastify';
import { cybatFastify } from '@cybat/sdk-node';

const fastify = Fastify({ logger: true });

cybatFastify(fastify, {
  apiKey: process.env.CYBAT_API_KEY!,
  gcpProjectId: process.env.GCP_PROJECT_ID!,
  serviceName: 'payment-service',
});

fastify.get('/health', async () => ({ status: 'ok' }));

fastify.listen({ port: 3000 });

Integración con NestJS

Monte en su función de inicio main.ts:

import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { cybatExpress } from '@cybat/sdk-node';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.use(cybatExpress({
    apiKey: process.env.CYBAT_API_KEY!,
    gcpProjectId: process.env.GCP_PROJECT_ID!,
  }));
  await app.listen(3000);
}
bootstrap();

Referencia de Configuración_

Opción Tipo Por Defecto Descripción
apiKey string Requerido Clave API sin procesar generada en Portal de Inteligencia → API Keys.
gcpProjectId string undefined ID de proyecto de GCP para enrutamiento en la nube y bloqueo automatizado en VPC Firewall / Cloud Armor.
awsProjectId string undefined ID de proyecto de AWS para enrutamiento en la nube de AWS.
serviceName string undefined Etiqueta que identifica qué servicio generó la telemetría (se muestra en incidentes).
captureBody boolean false Captura fragmentos del cuerpo de la petición. Redactado localmente en proceso antes de salir del servidor.
extraSensitiveKeys Iterable<string> undefined Nombres de campos adicionales para enmascarar como secretos (p. ej. ['account_number']).
statusFilter 'all' | 'errors' | fn 'all' Controla qué códigos de estado de respuesta capturados se reportan.
flushIntervalMs number 2000 Frecuencia con la que se envían los eventos de telemetría en búfer (en milisegundos).
maxRetries number 2 Reintentos máximos con retroceso exponencial ante fallos de red transitorios.
