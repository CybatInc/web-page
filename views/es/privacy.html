01 / INTRODUCCIÓN

El Protocolo

Cybat AI proporciona un agente de seguridad autónomo para GCP. Nos comprometemos a garantizar que sus datos se utilicen únicamente para fines de protección, nunca para elaboración de perfiles comerciales ni marketing.

02 / TELEMETRÍA

Límites de Ingestión

Nuestro agente procesa metadatos técnicos mediante una integración segura con Pub/Sub:

  • IP de Origen / Puerto de Destino
  • Encabezados HTTP / User Agents
  • Violaciones de Políticas de Armor
03 / INFERENCIA

Lógica Agéntica y SAIF

Utilizamos la API de Gemini (Vertex AI) para la inferencia. De conformidad con la Ley de IA de la UE (2026), sus datos se mantienen aislados y nunca se utilizan para entrenar modelos base globales.

// CERO_RETENCIÓN

Procesamiento sin estado. La inferencia se descarta inmediatamente tras el análisis.

// POSTURA_HUMANA

04 / CICLO DE VIDA

Política de Retención

Los informes de incidentes se conservan durante el período mínimo requerido para el análisis (generalmente 30 días), a menos que su política empresarial configure otro plazo.

05 / SOBERANÍA

RGPD / CCPA

Actuamos como Encargado del Tratamiento. Todos los datos permanecen dentro de las regiones de Google Cloud que especifique para garantizar el cumplimiento de las leyes locales de soberanía.
