Guía de Integración con Cloudflare_

La Integración de Cybat con Cloudflare combina telemetría de comportamiento fuera de banda en el edge con la aplicación automatizada de reglas de acceso IP en Cloudflare WAF. Al desplegar el ligero Cybat Edge Collector como un Cloudflare Worker, tus APIs obtienen inspección lógica de zero-days y huellas dactilares JA4 de clientes con 0 ms de latencia añadida a las respuestas de origen.

⚡ 0 ms de Latencia Añadida

Las peticiones al origen se reenvían de inmediato; la telemetría se despacha de forma asíncrona fuera de banda usando ctx.waitUntil().

🔒 Redacción en Memoria

Encabezados de autorización, tokens Bearer, cookies y campos de credenciales sensibles se depuran dentro del isolate perimetral antes del tránsito.

🛡️ Sincronización WAF Bidireccional

El agente de IA autónomo del SOC de Cybat crea bloqueos IP en Cloudflare WAF y retira las reglas automáticamente tras la resolución o retroalimentación negativa.

🏛️ Cómo Funciona el Edge Collector

Los proxies en línea tradicionales introducen viajes de ida y vuelta de red que elevan la latencia. Cybat desacopla la entrega de la respuesta del origen de la telemetría de seguridad:

Conecta Cloudflare Durante el Registro del Workspace

Al activar tu suscripción mediante el enlace Register with Cybat (desde Google Cloud Marketplace o la invitación de tu organización), configura Cloudflare como tu proveedor de defensa perimetral autónoma:

  1. Selecciona el Proveedor de Defensa Autónoma: En la pantalla de registro de Cybat, selecciona Cloudflare (WAF).
  2. Perfil de la Organización: Introduce el Nombre de tu Empresa (ej. LatAm - Fintech 21-500 - GCP & Cloudflare — salta al Paso 2 ↓), el ID único de Organización / Workspace y tu Correo de Administrador (utilizado para el inicio de sesión con Google SSO).
  3. Credenciales de Bloqueo Autónomo en Cloudflare WAF:
    • Token de API de Cloudflare: Un token bearer restringido creado en tu panel de Cloudflare con el permiso Firewall Access Rules: Edit (salta al Paso 2: Crear Token de API de Cloudflare ↓).
    • Account ID de Cloudflare: El identificador hexadecimal de 32 caracteres de tu cuenta que se encuentra en el panel de Cloudflare.

      Dónde encontrarlo: En el Panel de Cloudflare, selecciona cualquier dominio/zona → en la página Overview, baja por la barra lateral derecha hasta la sección API para copiar el Account ID (o cópialo directamente de la URL del navegador: dash.cloudflare.com/<ACCOUNT_ID>/...). Consulta el Paso 2.E: Obtener Account ID ↓ para más detalles.

    • Zone ID de Cloudflare (Opcional): El identificador de 32 caracteres de una zona específica si prefieres restringir los bloqueos IP automáticos a un dominio concreto en lugar de a toda la cuenta.

      Dónde encontrarlo: En el Panel de Cloudflare, selecciona tu dominio objetivo (ej. tudominio.com) → en la página Overview, desplázate por la barra lateral derecha hasta la sección API. El Zone ID se muestra justo sobre el Account ID con un botón de copiado de un clic. Consulta el Paso 2.F: Obtener Zone ID ↓ para más detalles.

  4. Confirmar y Registrar: Marca la casilla de verificación confirmando que el token de API posee los permisos de Firewall Access Rules y haz clic en Activate Account. Las credenciales se cifran en reposo con Google Cloud KMS y el agente autónomo de IA del SOC de Cybat las utiliza para bloquear IPs maliciosas.

Crea el Token de API Restringido de Cloudflare

Cybat utiliza tokens de API de Cloudflare con privilegios mínimos estándar (nunca utilices Global API Keys). Sigue estos pasos en el panel de Cloudflare:

A. Navega a API Tokens

Inicia sesión en dash.cloudflare.com. En la esquina superior derecha, haz clic en el icono de tu usuario → My Profile → selecciona API Tokens en la barra lateral izquierda.

B. Crea un Token Personalizado

Haz clic en Create Token, desplázate hasta el final bajo Custom Token y pulsa Get started.

C. Establece los Permisos Requeridos

Asigna un nombre a tu token (ej. Cybat SOC AI WAF Integration) y configura los siguientes permisos:

Ámbito Categoría de Permiso Nivel de Acceso Propósito
Account Firewall Access Rules Edit Permite a la IA de Cybat crear y eliminar bloqueos IP en tu cuenta.
Account Account Settings Read Permite a Cybat verificar credenciales y validar el ID de cuenta.
Zone (Opcional) Firewall Services Edit Habilita reglas a nivel de zona si limitas los bloqueos a zonas específicas.

D. Define Recursos y Crea el Token

  • Recursos de Cuenta: Selecciona Include → All Accounts (o tu cuenta de producción específica).
  • Recursos de Zona (Opcional): Selecciona Include → All Zones.
  • Haz clic en Continue to summary, revisa los ajustes y pulsa en Create Token.
  • Importante: Copia el Token de API generado inmediatamente. Cloudflare no almacena tokens en texto plano y no volverá a mostrarlo jamás.

E. Obtén tu Account ID de Cloudflare

El Account ID es un identificador hexadecimal único de 32 caracteres necesario para registrar tu organización de Cloudflare en Cybat. Puedes encontrarlo mediante cualquiera de estos métodos:

  • Desde la Vista General de Cualquier Dominio: En el Panel de Cloudflare, haz clic en cualquier dominio/zona de tu cuenta. En la página Overview, baja por la barra lateral derecha hasta la sección API y haz clic en Click to copy bajo Account ID.
  • Desde la URL del Navegador: Al visualizar cualquier página de cuenta o dominio en Cloudflare, el Account ID de 32 caracteres aparece directamente en la barra de direcciones: dash.cloudflare.com/<ACCOUNT_ID_32_CARACTERES>/...
  • Desde Workers & Pages: En la navegación izquierda, ve a Workers & Pages (o Compute) → tu Account ID se muestra en la barra lateral derecha.

F. Obtén tu Zone ID de Cloudflare (Opcional)

El Zone ID representa un dominio específico en tu cuenta de Cloudflare (ej. api.tuempresa.com). Es opcional: si se deja en blanco, Cybat aplicará las reglas de remediación autónomas en todas las zonas de la cuenta.

  • Dónde encontrarlo: En el Panel de Cloudflare, haz clic en el dominio/sitio web específico que deseas aislar.
  • En la pestaña Overview del dominio, baja por la barra lateral derecha hasta la sección API.
  • El Zone ID aparece situado justo encima del Account ID. Haz clic en Click to copy para copiar la cadena de 32 caracteres.
Verifica tu Token de API de Cloudflare: 
curl -s -X GET "https://api.cloudflare.com/client/v4/user/tokens/verify" \
  -H "Authorization: Bearer TU_TOKEN_DE_API_CLOUDFLARE" | jq .

Respuesta esperada: {"result": {"status": "active"}, "success": true}.

3

Despliega el Edge Collector desde el Panel de Cybat

No necesitas instalar herramientas de CLI locales ni gestionar código. El Cybat Edge Collector se despliega directamente en tu cuenta de Cloudflare en un solo clic a través del Panel de Inteligencia de Cybat:

Despliegue en 1 Clic desde la Sección API Keys

CERO CÓDIGO
  1. Abre la Sección API Keys: Inicia sesión en el Portal de Inteligencia de Cybat y navega a API Keys en la barra lateral (o visita https://intelligence.cybat.co/#/api-keys).
  2. Copia tu Clave de API de Cybat: Copia tu clave activa de Cybat (o genera una dedicada para la telemetría en el edge). La necesitarás durante la confirmación del despliegue en Cloudflare.
  3. Haz Clic en "Deploy to Cloudflare": En el banner destacado de Cloudflare Worker Edge Collector en la parte superior de la página de API Keys, pulsa el botón naranja Deploy to Cloudflare.
  4. Autoriza e Introduce tu Clave de API: Cloudflare se abrirá en una nueva pestaña. Selecciona tu cuenta de Cloudflare de destino, revisa el despliegue del worker y pega tu clave de API de Cybat cuando te solicite el secreto CYBAT_API_KEY.
  5. Completa el Despliegue: Pulsa Deploy. Cloudflare compilará y aprovisionará automáticamente el worker del edge collector en su red perimetral global.

Vincula la Ruta del Worker a tu Dominio / Zona de API

Una vez desplegado, indica a Cloudflare qué tráfico entrante debe enrutarse mediante el edge collector:

  1. En el panel de Cloudflare, navega a Compute (Workers) → Workers & Pages.
  2. Haz clic en el worker recién desplegado (cybat-edge-collector).
  3. Ve a Settings → Triggers → Routes y pulsa Add route.
  4. Define el patrón de ruta destino (ej. api.tudominio.com/* o tudominio.com/api/*).
  5. Selecciona tu Zona de Cloudflare activa en el desplegable y haz clic en Save.

⚙️ Referencia de Variables de Entorno y Enlaces

Estas variables se configuran automáticamente durante el despliegue o pueden ajustarse en el panel de Cloudflare bajo Worker Settings → Variables and Secrets:

Nombre de Variable Tipo Requerido Valor por Defecto Descripción
CYBAT_API_KEY Secret (Cifrado) Sí — Clave de API del inquilino Cybat obtenida en el Portal de Inteligencia.
PROJECT_ID Variable de Texto No "cloudflare" Etiqueta de proyecto / dominio utilizada para segmentar analíticas en Cybat.
CYBAT_INGESTION_URL Variable de Texto No "https://gcp-ingest.cybat.co" Endpoint gateway del clúster regional de ingesta de Cybat.
CYBAT_MAX_BODY_BYTES Variable de Texto No "65536" Límite máximo del cuerpo en bytes (64 KB) para proteger la memoria del isolate.

Verificación y Ciclo de Vida Operativo

Tan pronto como el tráfico alcanza tu dominio enrutado, el collector comienza a transmitir señales de comportamiento fuera de banda:

  • Globo de Amenazas 3D: Las peticiones entrantes aparecen en tiempo real en el panel de Cybat con los Ray IDs del edge de Cloudflare y los atributos de huella dactilar JA4 del cliente.
  • Bloqueo Automatizado de Exploits: Cuando una petición coincide con la lógica de un exploit zero-day (como BOLA, IDOR o inyección SQL), el agente autónomo de IA del SOC de Cybat crea instantáneamente una regla activa en Cloudflare WAF: 
    curl -s -X GET "https://api.cloudflare.com/client/v4/accounts/{account_id}/firewall/access_rules/rules" \
  -H "Authorization: Bearer TU_TOKEN" | jq '.result[] | {id, ip: .configuration.value, mode, notes}'
  • Desbloqueo en 1 Clic y Gestión de Falsos Positivos: Hacer clic en el icono de Pulgar hacia abajo en un incidente dentro del panel de Cybat purga automáticamente la regla en Cloudflare WAF (en los ámbitos de usuario, zona y cuenta). Hacer clic en el Pulgar hacia arriba reevalúa y vuelve a bloquear las amenazas activas de forma automática.
