Notas de la Versión_

Registro de cambios para Cybat Intelligence Engine. Cada versión detalla mejoras en la lógica del motor, características de la plataforma y cambios de infraestructura.

Versión 2.2.0

ÚLTIMA Octubre 2026

Lanzamiento SDK Java (v1.0.0)

  • co.cybat:cybat-sdk en Maven Central: Publicado el SDK oficial de Java compatible con Java 17+ y Jakarta Servlet 5.0+ (Spring Boot 3+, Tomcat 10+, Jetty 11+). Incluye cero dependencias externas en tiempo de ejecución, redacción de cuerpos en proceso local y enrutamiento multinube nativo.

Incorporación y Activación

  • Activación Instantánea en Marketplace: Canalización de incorporación de clientes optimizada para ejecutarse directamente a través de la API de Google Partner Procurement. Las aprobaciones de cuentas y activaciones de derechos ahora finalizan en segundos, sin compilaciones de infraestructura ni esperas.
  • Cero Sumideros de Logs: Se desmantelaron por completo los requisitos de sumideros de logs del lado del cliente y se eliminaron los permisos de escritura de logs a nivel de organización del flujo de configuración. La ingesta de telemetría ahora está 100% impulsada por el SDK de aplicación ligero.

Versión 2.1.0

Septiembre 2026

SDK de Python

  • cybat-sdk en PyPI: El nuevo paquete cybat-sdk lleva el mismo modelo de middleware a Python: Flask, Django y cualquier aplicación ASGI (FastAPI, Starlette). Instale con pip install cybat-sdk; el SDK de Go es el siguiente en la hoja de ruta.
  • Mismo contrato de red que Node.js: Las instancias del SDK de Python se comunican con el mismo protocolo de ingesta que @cybat/sdk-node, de modo que flotas en lenguajes mixtos informan a la misma organización y panel sin cambios en el backend.

Versión 2.0.0

Septiembre 2026

Ingesta Basada en SDK

  • @cybat/sdk-node: Nuevo paquete npm (@cybat/sdk-node) que se instala como middleware de Express y transmite el tráfico HTTP capturado directamente a Cybat, sin concesión de permisos IAM durante la incorporación.
  • API Gateway + Claves API: Nueva página de API Keys en el Panel de Inteligencia que permite a los administradores crear, nombrar, expirar y revocar instantáneamente las claves utilizadas por el SDK. Cada petición es validada por API Gateway en el borde de la red antes de llegar a los servidores de Cybat.
  • Canalización de Ingesta Serverless: El tráfico del SDK fluye a través del servicio Cloud Run sin servidor ingest-api y un tema compartido de Pub/Sub, reemplazando la canalización de Fluent Bit en GKE Autopilot para nuevos clientes.
  • Destino de Aplicación Configurable: El SDK acepta la opción gcpProjectId al iniciarse, indicándole al motor en qué proyecto aplicar bloqueos de cortafuegos.
  • Revocación Automática por Cancelación: Cuando una suscripción en Marketplace se cancela o suspende, todas las claves API de esa organización se revocan automáticamente.

Versión 1.2.0

Mayo 2026

Inteligencia de Amenazas

  • Enriquecimiento con Google Threat Intelligence: La canalización de análisis de IA ahora consulta la API de Google Threat Intelligence (VirusTotal v3) para cada IP antes de invocar a Gemini. La puntuación de reputación, recuentos de votos maliciosos, nombre de ASN y país se inyectan en el prompt.
  • Caché de Reputación de 6 Horas: Los resultados de GTI se almacenan en caché en Firestore bajo gti_cache/{ip_hash} con un TTL de 6 horas, reduciendo latencias y cuotas.
  • Degradación Agraciada: Las búsquedas de GTI se ejecutan en paralelo con consultas de historial. Fallos individuales de la API se gestionan sin bloquear la mitigación.
  • Cero Alteración de Lógica: Los datos de GTI enriquecen el contexto del prompt; la clasificación y los umbrales permanecen bajo control de Gemini.

Versión 1.1.0

Mayo 2026

Lista Blanca de IPs

  • Gestión de Lista Blanca para Administradores: Los administradores pueden mantener una lista blanca de IPs desde la sección Whitelist en el Panel de Inteligencia.
  • Omisión Completa de la Canalización: Las IPs en lista blanca se filtran antes del análisis de IA y de la aplicación de bloqueos, evitando consumo de cuotas y alertas innecesarias.
  • Salvaguarda de Ejecución: Una verificación secundaria dentro del servicio de aplicación garantiza que nunca se aplique una regla de bloqueo a una IP en lista blanca.
  • Ámbito por Organización: Las entradas de lista blanca se almacenan bajo organizations/{orgId}/whitelist/{ip} con aislamiento estricto entre organizaciones.

Retroalimentación y Desbloqueo Manual

  • Modal de Desbloqueo con Voto Negativo: Cuando un administrador marca un incidente bloqueado como incorrecto (👎), un cuadro de diálogo pregunta si desea desbloquear la IP, eliminando de inmediato la regla en Cloud Armor o VPC Firewall.
  • Retroalimentación de Incidentes No Bloqueados: Hacer clic en 👎 en un incidente detectado (no bloqueado) envía comentarios directamente sin modal adicional.
  • Aislamiento Organizacional: La API de desbloqueo valida que el incidente pertenezca a la organización del administrador solicitante.

Panel de Control

  • Tarjetas de Desglose por Gravedad: La barra superior de métricas ahora muestra cinco tarjetas: Gravedad Alta, Gravedad Media, Gravedad Baja, IPs Bloqueadas e IPs en Lista Blanca.
  • Vista de Lista Blanca: Una nueva página exclusiva para administradores muestra todas las IPs autorizadas con notas, creador y fecha.

Infraestructura y Operaciones

  • Cloud Scheduler — Reporte de Uso: Un trabajo de Cloud Scheduler activa /report-usage a los cinco minutos de cada hora para informar facturación a GCP Marketplace puntualmente.
  • Cloud Scheduler — Limpieza de Bloqueos: Un segundo trabajo ejecuta /cleanup cada 6 horas, eliminando reglas expiradas en Cloud Armor y VPC Firewall.
  • Token Autogenerado: El token de autenticación para ambos trabajos se genera automáticamente mediante Terraform y se guarda en Secret Manager.
  • API de Exportación de Uso: El endpoint /report-usage admite parámetros ?from=&to= y ?format=csv para descargas CSV de auditoría.
  • Índices Compuestos de Firestore: Se aprovisionan dos nuevos índices compuestos mediante Terraform para resolver problemas en escenarios de alto tráfico.

Versión 1.0.0

Abril 2026

Canalización de Ingesta

  • Capa de Ingesta en GKE: Puente de Pub/Sub y Fluent Bit ejecutándose como sidecar en GKE con procesamiento y extracción de IPs mediante filtros Lua.
  • Descubrimiento Multi-Inquilino: Descubrimiento automático de suscripciones Pub/Sub por organización en un ciclo de refresco de 60 segundos.
  • Latencia Cero-ETL: Retraso integral de la canalización por debajo de 7 segundos en estado estable.

Análisis de Amenazas con IA

  • Vertex AI Gemini 2.5 Flash Lite: El agente SOC envía lotes de telemetría por IP a Gemini 2.5 Flash Lite retornando veredictos estructurados (nivel de amenaza + explicación).
  • Caché de Veredictos de 24 Horas: Los veredictos se guardan en Firestore con claves hash HMAC-SHA256 para bloquear infractores reincidentes de inmediato sin consumir cuota de IA.
  • Ventana Histórica de 1 Hora: Se consideran los últimos 60 minutos de actividad por IP para brindar contexto conductual completo.
  • Control de Bloqueos Duplicados: Bloqueo de concurrencia para prevenir reglas redundantes si llegan múltiples lotes simultáneamente.

Aplicación de Medidas

  • Capa de Aplicación Dual: Intento inicial en VPC Firewall (Capa 3/4) con repliegue automático a Cloud Armor (Capa 7) en el Balanceador de Carga.
  • Ámbito por Proyecto: La mitigación se aplica al proyecto de GCP específico identificado en la telemetría, preservando el aislamiento entre proyectos.

Plataforma y Panel

  • Panel de Inteligencia: Centro de mando en tiempo real en intelligence.cybat.co con Globo de Amenazas 3D y feed en vivo.
  • Google SSO: Acceso seguro y unificado mediante Google Identity sin contraseñas adicionales.
  • Alertas en Slack: Notificaciones estructuradas automáticas ante incidentes de gravedad alta y media con detalles del atacante y mitigación.
  • Almacén de Incidentes en Firestore: Historial completo y pistas de auditoría registradas en Firestore.

Marketplace y Facturación

  • Integración con GCP Marketplace: Planes Starter, Professional y Enterprise medidos a través de GCP Service Control en su factura habitual de Google Cloud.
  • Activación Basada en Derechos: Validación en tiempo real de derechos de Marketplace antes de procesar telemetría.
