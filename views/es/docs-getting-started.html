Primeros Pasos_

Bienvenido a Cybat Intelligence Engine. La activación de sus operaciones de seguridad autónomas impulsadas por IA a través de Google Cloud Marketplace toma menos de 3 minutos. Siga estos pasos para comenzar a proteger su aplicación.

Requisitos Previos

Antes de suscribirse, confirme lo siguiente. No se requieren canalizaciones de infraestructura complejas ni roles de IAM a nivel de organización para configurar: su aplicación transmite telemetría directamente mediante una dependencia de SDK ligera.

Requerido

  • ✓ Una cuenta de facturación de GCP para la suscripción en Marketplace
  • ✓ Una aplicación que reciba tráfico HTTP en Python (Flask, Django, FastAPI), Node.js (Express, Fastify, NestJS) o PHP (Slim, Laravel, Symfony)
  • ✓ Capacidad de añadir una línea de middleware en el flujo de peticiones de su aplicación
  • ✓ Espacio de trabajo de Slack + URL de Incoming Webhook para la entrega de alertas

Altamente Recomendado

  • + Conocer el ID de proyecto de GCP donde se ejecuta su aplicación: habilita el bloqueo automático (VPC Firewall / Cloud Armor), no solo la detección
  • + Un almacén de secretos dedicado para la clave API (p. ej. Secret Manager): se muestra solo una vez tras la creación

Para conocer el contrato de red completo del SDK y los requisitos de aplicación, consulte la página de Especificaciones de Seguridad.

Paso 1: Suscribirse mediante Google Cloud Marketplace

  • Navegue a la Google Cloud Console y abra el Marketplace.
  • Busque Cybat Intelligence Engine y abra la ficha del producto.
  • Seleccione su cuenta de facturación y el plan correspondiente (Starter, Professional o Enterprise), luego haga clic en Suscribirse.
  • Acepte los Términos del Servicio. Una vez confirmado el pedido, haga clic en Registrarse con Cybat: se le redirigirá al Portal de Registro de Cybat Intelligence.

Paso 2: Registro Instantáneo y Configuración de Remediación

En la pantalla de registro, complete el perfil de su organización y la configuración de alertas:

  • Detalles de la Organización: Ingrese el Nombre de su Organización y el Correo Electrónico del Administrador principal.
  • Canales de Alerta: Proporcione la URL de Incoming Webhook de Slack y el canal para notificaciones instantáneas de amenazas.
  • Remediación Automatizada (Opcional): Ingrese el ID de Organización de GCP o el ID del Proyecto para generar un comando copiable de Cloud Shell. Al ejecutarlo se otorgan roles de IAM con privilegios mínimos (compute.securityAdmin, compute.networkViewer y browser para la aplicación autónoma de reglas en Cloud Armor / firewall VPC y desbloqueo desde el panel).
  • Haga clic en Activar Cuenta: su cuenta se verifica y activa inmediatamente en cuestión de segundos mediante Google Partner Procurement. Sin infraestructura que aprovisionar, sin compilaciones en segundo plano y sin demoras.

Paso 3: Iniciar Sesión en el Portal de Inteligencia

Cybat utiliza exclusivamente Google Identity: no se requiere una contraseña separada.

  • En la pantalla de inicio de sesión del portal, haga clic en Iniciar sesión con Google.
  • Seleccione su cuenta corporativa de Google Workspace. Las cuentas personales de Gmail no están autorizadas.
  • El panel de su organización se cargará de inmediato con analíticas en tiempo real, gestión de claves API y vistas de telemetría de seguridad.
Abrir Portal de Inteligencia →

Paso 4: Crear una Clave API

En el Portal de Inteligencia, abra API Keys en la barra lateral y haga clic en Crear Clave API. Asígnele un nombre y, opcionalmente, una fecha de expiración.

1.
La clave se muestra solo una vez: cópiela en su gestor de secretos de inmediato. No se puede recuperar nuevamente, únicamente revocar y reemplazar.
2.
La revocación es instantánea: eliminar una clave desde el panel se valida en vivo en la siguiente petición, sin almacenamiento en caché ni demoras.
3.
Sin modificaciones de infraestructura en su proyecto: la creación de una clave nunca altera la organización de GCP, roles IAM ni infraestructura en la nube.

Paso 5: Instalar el SDK

Agregue el SDK de Cybat a su aplicación como middleware. Es una única dependencia y una sola línea: sin demonios, sin sidecars y sin reenviadores externos.

● DISPONIBLE AHORA

Python / Flask, Django, FastAPI

pip install cybat-sdk
from flask import Flask
from cybat_sdk.integrations.flask import init_app

app = Flask(__name__)
init_app(app,
    api_key=os.environ["CYBAT_API_KEY"],
    gcp_project_id="your-gcp-project",  # habilita el bloqueo automático
)

Configure gcp_project_id con el ID del proyecto de GCP donde reside la infraestructura de su aplicación (o configúrelo a nivel de organización). El comando de Cloud Shell listo para ejecutar provisto durante el registro configura todos los roles necesarios con alcance estricto para la aplicación autónoma de reglas y el desbloqueo desde el panel. Si lo omite, Cybat seguirá detectando y alertando sobre amenazas en tiempo real, solo que no tendrá permisos para aplicar bloqueos automatizados en el firewall o Cloud Armor.

Django lee la configuración desde settings.py (agregue cybat_sdk.integrations.django.CybatMiddleware a MIDDLEWARE y defina CYBAT_API_KEY / CYBAT_GCP_PROJECT_ID); FastAPI y otras aplicaciones ASGI utilizan CybatASGIMiddleware mediante app.add_middleware(...). Consulte la Referencia SDK Python para la guía completa de configuración y detalles de redacción.

SDKs Disponibles por Lenguaje

Python (PyPI) — Activo Node.js (npm) — Activo PHP (Packagist) — Activo Java (Maven Central) — Activo Go — próximamente

Instale directamente vía PyPI (cybat-sdk), npm (@cybat/sdk-node), Composer (cybat/sdk) o Maven Central (co.cybat:cybat-sdk).

¿Detrás de un balanceador de carga o proxy inverso?

Configure el mecanismo estándar de su framework para confiar en X-Forwarded-For (p. ej. ProxyFix de Werkzeug para Flask) para que el SDK lea la IP real del cliente en lugar de la dirección del proxy.

SIN CAMBIOS EN CÓDIGO

Si el tráfico de su aplicación pasa a través de Cloudflare, ni siquiera necesita instalar un SDK o modificar el código fuente de su aplicación. Despliegue el Cybat Edge Collector directamente en su cuenta de Cloudflare para capturar telemetría conductual con cero latencia y sincronizar reglas automatizadas de acceso por IP en el WAF.

Paso 6: Verificar que la Detección esté Activa

Despliegue su aplicación y genere tráfico. Segundos después de que una petición llegue a su aplicación instrumentada con el SDK, regrese al Portal de Inteligencia; debería observar:

  • Su aplicación listada como Conectada en la barra lateral del panel.
  • El Globo de Amenazas 3D poblándose con actividad desde los orígenes geográficos de su tráfico.
  • Cualquier amenaza detectada apareciendo en el feed de Incidentes con análisis generado por Gemini y el estado de mitigación.

Si no aparece nada en unos minutos, confirme que el middleware esté montado antes de sus rutas y que la clave API no haya sido revocada ni haya expirado.

Cybat Intelligence Engine ahora está monitoreando activamente su superficie en la nube.
