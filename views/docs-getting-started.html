Getting Started_

Welcome to the Cybat Intelligence Engine. Activating your autonomous AI-driven security operations through the Google Cloud Marketplace takes under 10 minutes. Follow these steps to start protecting your application.

Prerequisites

Before subscribing, confirm the following. There's no log export or org-level IAM to configure — just an app that can install a small SDK dependency.

Required

  • ✓ A GCP billing account for Marketplace subscription
  • ✓ A Node.js, Python, or Go application receiving HTTP traffic
  • ✓ Ability to add one middleware line to your app's request pipeline
  • ✓ Slack workspace + Incoming Webhook URL for alert delivery

Strongly Recommended

  • + Know the GCP project ID your app runs in — unlocks automatic blocking (VPC Firewall / Cloud Armor), not just detection
  • + A dedicated secret store for the API key (e.g. Secret Manager) — it's shown once at creation

For the full SDK wire contract and enforcement requirements, see the Security Specs page.

Step 1: Subscribe via Google Cloud Marketplace

  • Navigate to the Google Cloud Console and open the Marketplace.
  • Search for Cybat Intelligence Engine and open the product listing.
  • Select your billing account and the appropriate plan (Starter, Professional, or Enterprise), then click Subscribe.
  • Accept the Terms of Service. Once the subscription is confirmed, click Register with Cybat — you will be redirected to the Cybat Intelligence Portal.

Step 2: Sign In to the Intelligence Portal

Cybat uses Google Identity exclusively — no separate password is required.

  • At the portal login screen, click Sign in with Google.
  • Select your corporate Google Workspace account. Personal Gmail accounts are not authorized.
  • On first login, your Organization profile is automatically provisioned — a unique orgId is assigned to your account and linked to your Marketplace billing identifier.
Open Intelligence Portal →

Step 3: Create an API Key

In the Intelligence Portal, open API Keys in the sidebar and click Create API Key. Give it a name and, optionally, an expiration date.

1.
The raw key is shown once — copy it into your secret manager immediately. It cannot be retrieved again, only revoked and replaced.
2.
Revocation is instant — deleting a key from the dashboard is checked live on the very next request, not cached or delayed.
3.
No infrastructure changes in your project — creating a key never touches your GCP org, IAM, or logging configuration.

Step 4: Install the SDK

Add the Cybat SDK to your app as middleware. It's a single dependency and a single line — no daemons, no sidecars, no log shipping agents.

Node.js / Express

npm install @cybat/sdk-node
import { cybatExpress } from '@cybat/sdk-node'

app.use(cybatExpress({
  apiKey: process.env.CYBAT_API_KEY,
  gcpProjectId: 'your-gcp-project', // enables automatic blocking
}))

Set gcpProjectId to the GCP project your app's infrastructure lives in, and grant soc-ai-agent@cybat-public.iam.gserviceaccount.com compute.securityAdmin + compute.networkViewer on it (a ready-to-run Cloud Shell command is shown in the portal). Skip it and Cybat still detects and alerts on threats — it just won't have a project to block against.

Python and Go SDKs are on the roadmap — reach out if you need one sooner.

Behind a load balancer or reverse proxy?

Set app.set('trust proxy', ...) so the SDK reads the real client IP from X-Forwarded-For instead of your proxy's own address.

Step 5: Verify Detection is Active

Deploy your app and generate some traffic. Within seconds of a request reaching your SDK-instrumented app, return to the Intelligence Portal — you should see:

  • Your app listed as Connected in the dashboard sidebar.
  • The 3D Threat Globe populating with activity from your traffic's geographic origins.
  • Any detected threats appearing in the Incident feed with Gemini-generated analysis and enforcement status.

If nothing appears within a few minutes, confirm the middleware is mounted before your routes and that the API key hasn't been revoked or expired.

The Cybat Intelligence Engine is now actively monitoring your cloud surface.
