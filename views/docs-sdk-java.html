Quick Start_

Four steps from dependency configuration to live autonomous threat protection.

1.

Add the dependency

Available directly from Maven Central for Maven or Gradle:

<dependency>
    <groupId>co.cybat</groupId>
    <artifactId>cybat-sdk</artifactId>
    <version>1.0.0</version>
</dependency>
2.

Create an API key

From the Intelligence Portal → API Keys. Store it as an environment variable or secret named CYBAT_API_KEY.

3.

Register the CybatFilter bean

In Spring Boot 3+, register a FilterRegistrationBean<CybatFilter> with highest precedence — see Framework Code Samples below.

4.

Generate traffic, watch the dashboard

Traffic appears in the Intelligence Portal within seconds — service listed as Connected, Threat Globe actively tracking IP origins, and incidents reported in real time.

Installation_

Install via your build tool of choice. Requires Java 17+ and targets jakarta.servlet (Servlet 5.0+ / Jakarta EE 9+).

Apache Maven

Add to your pom.xml:

<dependency>
    <groupId>co.cybat</groupId>
    <artifactId>cybat-sdk</artifactId>
    <version>1.0.0</version>
</dependency>

Gradle

Add to your build.gradle:

implementation 'co.cybat:cybat-sdk:1.0.0'
Zero Runtime Dependencies

The Java SDK relies exclusively on java.net.http.HttpClient (built into JDK 11+) and a hand-crafted zero-dependency JSON parser. It avoids third-party JSON libraries (Jackson, Gson, org.json) entirely, eliminating transitive classpath collisions with host application dependencies. The jakarta.servlet-api dependency is marked <scope>provided</scope> and is supplied by your container.

Framework Code Samples_

Drop-in configuration snippets for Spring Boot 3+ and standard Jakarta Servlet containers.

Spring Boot 3+ (Spring MVC)

Register a FilterRegistrationBean in your configuration class. Setting Ordered.HIGHEST_PRECEDENCE ensures Cybat instruments all inbound requests before subsequent controller interceptors:

package com.example.demo.config;

import co.cybat.sdk.CybatFilter;
import co.cybat.sdk.Options;
import org.springframework.boot.web.servlet.FilterRegistrationBean;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.Ordered;

@Configuration
public class CybatConfig {

    @Bean
    public FilterRegistrationBean<CybatFilter> cybatFilter() {
        Options options = Options.builder(System.getenv("CYBAT_API_KEY"))
            .gcpProjectId("my-gcp-project") // enables automated Cloud Armor / VPC Firewall blocking
            .serviceName("checkout-service")
            .captureBody(true)
            .build();

        CybatFilter filter = new CybatFilter(options);

        FilterRegistrationBean<CybatFilter> registration = new FilterRegistrationBean<>(filter);
        registration.addUrlPatterns("/*");
        registration.setOrder(Ordered.HIGHEST_PRECEDENCE);
        return registration;
    }
}

Plain Jakarta Servlet Container (Tomcat 10+, Jetty 11+)

Register programmatically in a ServletContextListener or servlet initializer:

import co.cybat.sdk.CybatFilter;
import co.cybat.sdk.Options;
import jakarta.servlet.FilterRegistration;
import jakarta.servlet.ServletContext;
import jakarta.servlet.ServletContextEvent;
import jakarta.servlet.ServletContextListener;
import jakarta.servlet.annotation.WebListener;

@WebListener
public class CybatInitializer implements ServletContextListener {

    @Override
    public void contextInitialized(ServletContextEvent sce) {
        ServletContext ctx = sce.getServletContext();

        Options options = Options.builder(System.getenv("CYBAT_API_KEY"))
            .gcpProjectId("my-gcp-project")
            .serviceName("legacy-api")
            .build();

        CybatFilter filter = new CybatFilter(options);
        FilterRegistration.Dynamic reg = ctx.addFilter("cybatFilter", filter);
        reg.addMappingForUrlPatterns(null, false, "/*");
    }
}
Behind a load balancer or reverse proxy?

CybatFilter reads the client IP via request.getRemoteAddr(). When deployed behind a load balancer, reverse proxy, or Cloud CDN, ensure your servlet container is configured to parse forwarded headers (e.g., Tomcat's RemoteIpValve or Spring's server.forward-headers-strategy=native) so the real client IP is reported rather than the proxy.

Automatic Cloud Armor & VPC Firewall Enforcement

Setting gcpProjectId activates real-time classification and alerting immediately. To enable Cybat to autonomously block detected malicious IPs via Cloud Armor and VPC Firewall rules, grant the Cybat Service Account the roles/compute.securityAdmin and roles/compute.networkViewer roles on your target GCP project.

Multi-Cloud Routing_

Set exactly one of gcpProjectId or awsProjectId on the options builder — required, and never both on the same instance. Whichever you configure determines where data is routed automatically.

You set Data goes to Status
gcpProjectId("...") gcp-ingest.cybat.co Live
awsProjectId("...") aws-ingest.cybat.co Not yet implemented

An application deployed across both cloud providers should register two distinct CybatFilter instances. Setting both properties on a single Options.Builder will throw an IllegalArgumentException at build time.

Configuration Reference_

Constructed via the type-safe fluent builder Options.builder(apiKey).

Option Type Default Description
apiKey String Required API key generated from Intelligence Portal → API Keys.
gcpProjectId String null Required unless awsProjectId is set. Routes to GCP ingest and enables automated Cloud Armor / VPC Firewall mitigation.
awsProjectId String null Routes to AWS ingest endpoint (coming soon).
serviceName String null Optional identifier displayed on incident timelines and telemetry events.
ingestUrl String auto Overrides cloud destination URL (primarily for local mock testing).
flushIntervalMs long 2000 Interval in milliseconds between background flushes of buffered events.
maxBatchSize int 100 Triggers an immediate background flush when the in-memory queue reaches this size.
maxRetries int 2 Max exponential backoff retries before dropping a failed telemetry batch.
retryBackoffMs long 500 Base retry delay; doubles exponentially on successive attempts.
statusFilter StatusFilter StatusFilter.ALL Predicate filter (StatusFilter.ALL, StatusFilter.ERRORS, or custom lambda status -> status != 304).
captureBody boolean false Enables in-process redaction and telemetry capture of request bodies.
bodyMaxBytes int 2048 Maximum size in bytes of the post-redaction body excerpt (capped at 8192).
bodyStatusFilter StatusFilter null Captures request bodies only when the response status matches this predicate.
extraSensitiveKeys Collection<String> null Additional field names to mask during in-process redaction (e.g. Set.of("account_number", "ssn_last_4")).

Request Bodies & Redaction_

captureBody is disabled by default. Enabling body capture supplies the Intelligence Engine with critical attack indicators (SQLi, command injection, credential stuffing, prompt injection), while preserving strict privacy guarantees:

1.
Zero-leak in-process masking: Before events leave memory, payloads are parsed and masked locally. Email addresses, Luhn-valid credit card numbers, Bearer/JWT tokens, API keys, and sensitive fields (password, token, cvv, ssn) are permanently redacted.
2.
Attack shape preservation: Sensitive values are replaced with content-free structural descriptors such as [REDACTED len=14 sus=quote,comment]. Malicious patterns remain visible to threat models without exposing raw user secrets.
3.
Dual-stream request wrapping: CybatFilter wraps the incoming request to intercept both getInputStream() and getReader() safely. Only bodies actually read by downstream application code are captured, bounded by an in-flight 1 MiB buffering cap. Multipart and binary streams are skipped entirely.
4.
Custom sensitive field masking: Extend redaction with your own domain-specific fields via extraSensitiveKeys. Field matching is exact and case-insensitive to prevent accidental over-masking of unrelated parameters.
Options options = Options.builder(System.getenv("CYBAT_API_KEY"))
    .gcpProjectId("my-gcp-project")
    .captureBody(true)
    .bodyMaxBytes(4096)
    .extraSensitiveKeys(java.util.Set.of("account_number", "ssn_last_4", "medical_record_id"))
    .build();
