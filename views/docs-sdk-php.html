PHP SDK Reference_

PSR-15 middleware for Slim, Laravel, Symfony, and Laminas that reports HTTP traffic directly to the Cybat Intelligence Engine.

● AVAILABLE NOW cybat/sdk on Packagist PHP 8.1+ PSR-15 Middleware Standard

Quick Start_

Four steps from an empty terminal to live detection.

1.

Install the package

composer require cybat/sdk
2.

Create an API key

From the Intelligence Portal → API Keys. Store it in your environment as CYBAT_API_KEY.

3.

Add the middleware

One import, one middleware call — see Framework Code Samples below.

4.

Generate traffic, watch the dashboard

Requests appear in the Intelligence Portal within seconds — app listed as Connected, Threat Globe populating, incidents in the feed.

Slim Framework 4

Add CybatMiddleware directly to your Slim application pipeline:

<?php

use Cybat\Sdk\Collector;
use Cybat\Sdk\Options;
use Cybat\Sdk\CybatMiddleware;
use Slim\Factory\AppFactory;

$app = AppFactory::create();

$options = new Options(
    apiKey: $_ENV['CYBAT_API_KEY'],
    gcpProjectId: $_ENV['GCP_PROJECT_ID'],
    serviceName: 'user-service',
    captureBody: true,
    extraSensitiveKeys: ['account_number', 'ssn_last_4']
);

$collector = new Collector($options);
$app->add(new CybatMiddleware($collector));

$app->get('/api/users', function ($request, $response) {
    $response->getBody()->write(json_encode(['status' => 'ok']));
    return $response->withHeader('Content-Type', 'application/json');
});

$app->run();

Laravel Integration

Register in app/Http/Kernel.php or register via ServiceProvider:

<?php

namespace App\Http\Middleware;

use Closure;
use Cybat\Sdk\Collector;
use Cybat\Sdk\Options;

class CybatLaravelMiddleware
{
    private static ?Collector $collector = null;

    public function handle($request, Closure $next)
    {
        if (self::$collector === null) {
            self::$collector = new Collector(new Options(
                apiKey: config('services.cybat.api_key'),
                gcpProjectId: config('services.cybat.gcp_project_id'),
                serviceName: 'laravel-api'
            ));
        }

        $response = $next($request);

        // Capture request telemetry
        self::$collector->captureRequest(
            method: $request->method(),
            url: $request->fullUrl(),
            status: $response->getStatusCode(),
            remoteIp: $request->ip(),
            headers: $request->headers->all(),
            body: $request->getContent()
        );

        return $response;
    }
}

Symfony Integration

Add as an EventSubscriber on KernelEvents::TERMINATE:

<?php

namespace App\EventSubscriber;

use Cybat\Sdk\Collector;
use Cybat\Sdk\Options;
use Symfony\Component\EventDispatcher\EventSubscriberInterface;
use Symfony\Component\HttpKernel\Event\TerminateEvent;
use Symfony\Component\HttpKernel\KernelEvents;

class CybatSubscriber implements EventSubscriberInterface
{
    private Collector $collector;

    public function __construct()
    {
        $this->collector = new Collector(new Options(
            apiKey: $_ENV['CYBAT_API_KEY'],
            gcpProjectId: $_ENV['GCP_PROJECT_ID'],
            serviceName: 'symfony-app'
        ));
    }

    public static function getSubscribedEvents(): array
    {
        return [KernelEvents::TERMINATE => 'onKernelTerminate'];
    }

    public function onKernelTerminate(TerminateEvent $event): void
    {
        $request = $event->getRequest();
        $response = $event->getResponse();

        $this->collector->captureRequest(
            method: $request->getMethod(),
            url: $request->getUri(),
            status: $response->getStatusCode(),
            remoteIp: $request->getClientIp(),
            headers: $request->headers->all(),
            body: $request->getContent()
        );
    }
}

Configuration Reference_

Option Type Default Description
$apiKey string Required Raw API key generated from Intelligence Portal → API Keys.
$gcpProjectId ?string null GCP Project ID for cloud routing and automated VPC Firewall / Cloud Armor blocking.
$awsProjectId ?string null AWS Project ID for AWS cloud routing.
$serviceName ?string null Label identifying which service generated the telemetry.
$captureBody bool false Captures request body excerpts. Redacted in-process before leaving server.
$extraSensitiveKeys ?array null Extra field names to treat as secrets for masking (e.g. ['account_number']).
$statusFilter string|callable 'all' Controls which captured response status codes are reported.
$flushIntervalMs int 2000 How often to flush buffered telemetry events in milliseconds.
